## 可复现检查

词典与搜索检查（需要 Node.js，无第三方依赖）：

```powershell
node .\tests\validate.cjs
node .\tests\validate.cjs "已安装或解压的原扩展目录"
```

独立临时目录的安装/卸载检查（不改动指定的原扩展目录）：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tests\install-roundtrip.ps1 -OriginalExtension "原扩展目录"
```

维护者如另有旧补丁，可追加 `-LegacyPatchPath "旧补丁目录"` 检查升级。发布包本身不需要附带旧版本。
